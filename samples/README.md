# 올려 볼 산출방법서 샘플

이 폴더의 파일을 앱의 **[열기]** 로 고르거나 창에 끌어다 놓아 "산출방법서 → 조건" 기능을 시험합니다.
파일마다 무엇이 읽히는지는 `tests/samples.test.ts` 가 매번 확인합니다 — 아래 표와 같습니다.

> 02·03 은 실제 회사 산출방법서·사업방법서의 **모양만 본떠 새로 쓴 가상의 문서**입니다(실제 문서를 옮긴 것이 아님).
> Word 로 고쳐 올리는 **표준 산출방법서**(`표준_산출방법서_종신보험` 등)는 [`../standards/`](../standards/README.md) 에 있습니다.

## 5분 시험 순서

1. 앱을 엽니다 — `npm run dev` 후 http://localhost:3000 (또는 배포 주소).
2. **[열기] → `02_실무양식_든든건강보험_산출방법서.docx`**
   - 알림: "문단 N·표 N에서 조건 N개를 읽었습니다"
   - 왼쪽 입력 카드: M03 적용이율 2.75% · 표준이율 2.25% · 적용해지율 3%, M04 위험률 3개, M06 사업비 6줄
   - 문서의 "기준: 가입나이 40세 · 100세만기 · 20년납" 은 읽지 않습니다 — 계약 한 점은 자유설계보험 상품 만들기의 M02 계약정보에서 정합니다
   - [YAML] 탭: 값 옆 주석이 원문 위치와 확신도입니다 (예: `# 본문 N줄 · 본문 규칙`, 표에서 읽은 값은 `# 표 1 · 표에서 직접`)
   - 오른쪽 **[원문]** 탭: 줄마다 읽은 조건 딱지. 딱지 줄을 누르면 왼쪽 칸이, 왼쪽 칸을 고르면 그 원문 줄이 노랗게 표시됩니다
   - 비어 있는 칸(담보)은 직접 채웁니다 — 산출방법서가 바로 바뀝니다
3. **[열기] → `03_실무양식_든든건강보험_사업방법서_발췌.docx`** → M01 가입 조건 표 3행(병합 칸은 위 행 값을 이어 읽음), 납입주기 월납·연납
4. **[열기] → `05_자유설계보험_암보험_MethodSpec.json`** → 주계약·특약 담보 2개, 아래 위험률 표 창에 4열이 들어옵니다
5. [샘플 → 종신보험] 을 연 뒤 아래 위험률 표 창 **[파일 올리기] → `06_위험률표_종신_남녀.xlsx`**(또는 .csv) → 연령·사망률·장해율이 남·여로 자동 연결 → 산출방법서 위험률 표에 "40~110세 71행"
   - **위험률 표 → 조건 → 계산 (처음이라면 이 순서)**: [샘플 → 종신보험] → **[파일 올리기] → `08_위험률표_종합_남녀.csv`** → 사망률(남·여)·80% 이상 장해율은 조건의 위험률에 이어지고, 조건에 없던 2대질병·3대질병·암(남·여)은 M04 에 새 위험률로 더해져 이어집니다(유형 확인) → 산출방법서 맨 뒤 "별첨 — 위험률 표" → **[내보내기 → MethodSpec .json]** → 자유설계보험 `/method` 에서 열어 [상품 만들기에 넣기] → 계약정보 성별의 표로 보험료 계산. M04 에서 [＋ 위험률] 을 누르면 표에 그 이름의 빈 열이 생기고(상태줄 "표 없음"), 값을 붙여넣으면 이어집니다.
6. **[열기] → `07_스캔본_든든건강보험.pdf`** (또는 `_1쪽.png`) → **그림으로 읽기** 창 — 쪽을 고르고 본인의 Anthropic API 키를 넣어 [1쪽 보내기] (약 $0.07). 02 와 같은 이율·사업비가 나오는지 대조합니다(`docs/이미지-PDF-변환-설계.md`)
7. 고쳐서 반영: **[열기] → `01_앱양식_종신보험_산출방법서.tex`** → [LaTeX] 탭에서 `적용이율 i & 2.500` 을 `3.000` 으로 → **[조건에 반영]** → 왼쪽 M03 이 3% 로 바뀌고 조건 파일 주석은 남습니다
8. Word·한글로 고쳐 반영: [샘플 → 종신보험] → **[Word]** 탭 [Word 내려받기] → Word 에서 적용이율 `2.500%` 를 `3.000%` 로, `[식] 순보험료·기준연납순보험료` 아래 식의 `20` 을 `25` 로 고쳐 저장 → **[고친 Word 올리기]** → "basis.interest · formulas" 두 건만 반영

## 조건 샘플 여덟 (`lib/samples.ts`)

**공유용 [샘플] 메뉴에는 종신보험 · 암보험 둘만 보입니다**(첫 화면은 종신보험). 나머지는 주소 뒤에 `?all` 을 붙이면 메뉴에 모두 나오고, `?sample=<id>`(예: `?sample=twoMajor`)로 바로 열 수 있습니다.

| 공유 샘플 | 구성 | 40세 남 · 20년납 · 월납 · 가입금액 1억 |
|---|---|---|
| 종신보험 | 사망·80% 이상 장해 — 탈퇴 전부가 급부 · 종신(110세) | 253 → 253,000원 |
| 암보험 | 주계약 암 진단(1배) + [암입원특약] 1일당 3만원 + [암수술특약] 가입금액 × 0.1 · 100세 만기 · 셋 다 90일 면책 · 암 진단 시 납입면제(특약도) · 사망률 미반영 | 216 + 22,421(1일 3만원 → 6,720원) + 178 → 240,520원 (담보 보험료는 10원 미만 버림) |

위험률 값은 앱에 든 공개 기본 위험률(`lib/base-rates.ts`)이고, 근거는 모두 `경험생명표(가상) …` 입니다. 탈퇴율은 질병끼리 곱, 사망과는 겹치는 부분 절반으로 결합하고, 보험기간 "N세"는 N세 만기(N−1세까지, 종신은 110세의 해까지)입니다.
식·계산이 기존 산출방법서(자유설계보험 `docs/산출방법서_설계형보험.md` · `산출방법서_일반종신보험.md` · `납입면제특약_정리.md`)와 어떻게 같고 다른지는 카드뉴스 "샘플 산출 검토" 에 정리했습니다.

| 샘플 | 탈퇴 사유(집단) · 급부 | 40세 남 · 20년납 · 월납 |
|---|---|---|
| 종신보험 | 사망·80% 이상 장해 — 탈퇴 전부가 급부 | 10만원당 253 (1억 → 253,000원) |

### 시험하다 발견한 점

- **PDF 도 표준 양식이면 Word 와 똑같이 읽힙니다** (`tests/pdf-vs-word.test.ts` · 10번 견본). PDF 에는 표 구조도 첨자도 없어서 글자 좌표로 되살립니다 —
  열 경계는 표 덩이 전체의 빈 띠로 찾고, 칸 안에서 줄바꿈된 줄·쪽마다 되풀이되는 머리글은 이어 붙이고, 본문보다 작고 아래·위로 치우친 글자는 첨자(`l_{x+t}` · `v^{t+½}`)로 되살립니다.
  Word 가 수식을 PDF 로 쓸 때 쓰는 수학 기울임 글자(𝑙 𝑥 𝛴 𝛼)도 보통 글자로 되돌립니다.
  다시 만들 때: `DOCS_UPDATE=1 node node_modules/vitest/vitest.mjs run tests/pdf-vs-word.test.ts` (→ .docx) → `powershell -ExecutionPolicy Bypass -File scripts/make-sample-pdf.ps1` (→ .pdf, Word COM).
- **회사 양식 PDF 는 예전 방식으로 읽습니다** — 줄마다 칸을 나누는 방식에 맞춰져 있어(α₁ 을 `α1` 로 읽는 것 등) 표준 양식일 때만 새 방식으로 다시 읽습니다.

- **α_P 해석 (고침)** — "초년도 기준연납순보험료 × MIN(보험기간,20) … 12%" 는 이 앱의 영업보험료 식이 α_P 를 20년 기준 배수로 쓰므로 `12% × 20 = 2.4배` 로 읽습니다(보장기간이 20년보다 짧으면 식이 n/20 을 곱함). 실제 문서 2건("3.50%×Min(보험기간, 20년)" → 0.7배, "X MIN(보험기간,20) 15%" → 3배)도 같은 규칙입니다.
- 파일을 열면 조건 **전체가 새 문서로 바뀝니다.** 산출방법서(02)와 사업방법서(03)를 합쳐 한 조건으로 만드는 "더해 읽기"는 아직 없습니다(제안).

| **표준 산출방법서** Word `.docx` | [Word] 탭에서 받아 Word 에서 고침 (규칙: `standards/README.md`) | [고친 Word 올리기] (바뀐 것만) 또는 [열기] (새로) | 값 + **수식 · 주석 · 절** (Word 수식 편집기로 넣은 식 포함) |
| 다른 양식 Word `.docx` | Word 에서 표 칸·값을 고치고 저장 | [열기] 또는 [고친 Word 올리기] | 표·본문 규칙으로 읽히는 값 |
| 다른 양식 한글 `.hwpx` · `.hwp` | 02 `.docx` 를 한글로 열어 [다른 이름으로 저장 → HWPX 또는 HWP] | 위와 같음 | HWPX 는 표까지, HWP(5.x)는 아직 문단만(사업비 표가 빠질 수 있음 → HWPX 권장) |
| PDF | 고치는 형식이 아님 — Word·한글에서 [PDF 로 저장]한 글자 있는 PDF | [열기] (표가 깨지면 [원문] 탭 [그림으로 다시 읽기]) | 문단·단순한 표 |
| 스캔 PDF · PNG · JPG | 고치는 형식이 아님 | [열기] → 그림으로 읽기 (API 키) | 옮겨 적은 글에서 규칙으로 읽히는 값 |
| MethodSpec `.json` | 자유설계보험 `/method` 가 내보냄 (고급: VS Code) | [열기] | 전부 + 위험률 표 |
| 위험률 표 `.csv` · `.xlsx` | Excel 에서 값을 고치거나, 표를 복사해 위험률 표 창에 붙여넣기(Ctrl+V) | 위험률 표 창 | 연령 × 위험률 값(첫 행은 열 이름) |
| 산출방법서 속 별첨 위험률 표 (PDF·Word·한글) | 첫 열이 연령, 나머지가 값인 표 | [열기] · [고친 Word 올리기] | 위험률 표 창으로 — 열 이름이 위험률 이름과 같으면 바로 이음 |

## 샘플을 만든 방법

- **01** — 앱의 [샘플 → 종신보험] 조건으로 앱이 낸 `.md` · `.tex` → pandoc 으로 `.docx`, 앱 HTML → 크롬 인쇄로 `.pdf`
- **02 · 03** — 손으로 쓴 `.md` (실제 산출방법서·사업방법서 25건의 모양을 본뜸) → pandoc `.docx`, pandoc HTML → 크롬 인쇄 `.pdf`
- **04** — 앱 샘플 "무해지환급형 암보험" 조건 파일 (샘플을 고치면 다시 뽑는다 — 보장금액은 배수)
- **05** — 자유설계보험 레시피 "암 진단 + 암입원 특약" → `planToSpec`
- **06** — 자유설계보험에 들어 있는 사망률 · 80% 이상 장해율(40~110세, 남·여)
- **07** — 02 PDF 1쪽을 그림(PNG)으로 찍고, 그 그림만 넣은 PDF
- **09** — Studio `VERIFY_UPDATE=1 … tests/default-product.test.ts` (조건 + 공개 기본 위험률 → JSON) → 자유설계보험 `VERIFY_UPDATE=1 … tests/ui/default-product.test.ts` (계산 → `_계산결과.json`) → `python scripts/make-verify-xlsx.py` (엑셀 수식) → `powershell -ExecutionPolicy Bypass -File scripts/check-verify-xlsx.ps1` (엑셀로 다시 계산 · 차이 0 확인 · 값 저장). 앱의 엑셀은 `XLSX_UPDATE=1 … tests/calc-xlsx.test.ts` (→ `_보험료계산.xlsx`) → `scripts/check-calc-xlsx.ps1` (엑셀 재계산 = 앱 = 엔진)
- **08** — `node scripts/make-rate-sample.mjs` (곰페르츠 곡선으로 만든 가상의 값 — 실제 경험률이 아님)
