# 올려 볼 산출방법서 샘플

이 폴더의 파일을 앱의 **[열기]** 로 고르거나 창에 끌어다 놓아 "산출방법서 → 조건" 기능을 시험합니다.
파일마다 무엇이 읽히는지는 `tests/samples.test.ts` 가 매번 확인합니다 — 아래 표와 같습니다.

> 02·03 은 실제 회사 산출방법서·사업방법서의 **모양만 본떠 새로 쓴 가상의 문서**입니다(실제 문서를 옮긴 것이 아님).
> Word·한글로 고쳐 올리는 **표준 산출방법서**(`표준_산출방법서_종신보험` 등)는 [`../standards/`](../standards/README.md) 에 있습니다.

## 5분 시험 순서

1. 앱을 엽니다 — `npm run dev` 후 http://localhost:3000 (또는 배포 주소).
2. **[열기] → `02_실무양식_든든건강보험_산출방법서.docx`**
   - 알림: "문단 N·표 N에서 조건 N개를 읽었습니다"
   - 왼쪽 입력 카드: M03 적용이율 2.75% · 표준이율 2.25% · 적용해지율 3%, M04 위험률 3개, M06 사업비 6줄
   - 문서의 "기준: 가입나이 40세 · 100세만기 · 20년납" 은 읽지 않습니다 — 계약 한 점은 자유설계보험 상품 만들기의 M02 계약정보에서 정합니다
   - [YAML] 탭: 값 옆 주석이 원문 위치와 확신도입니다 (예: `# 본문 N줄 · 본문 규칙`, 표에서 읽은 값은 `# 표 1 · 표에서 직접`)
   - 오른쪽 **[원문]** 탭: 줄마다 읽은 조건 딱지. 딱지 줄을 누르면 왼쪽 칸이, 왼쪽 칸을 고르면 그 원문 줄이 노랗게 표시됩니다
   - 비어 있는 칸(담보)은 직접 채웁니다 — 산출방법서가 바로 바뀝니다
3. **[열기] → `03_실무양식_든든건강보험_사업방법서_발췌.docx`** → M01 가입 조건 표 3행(병합 칸은 위 행 값을 이어 읽음), 납입주기 월납·연납
4. **[열기] → `05_자유설계보험_암보험_MethodSpec.json`** → 주계약·특약 담보 2개, 아래 위험률 표 창에 4열이 들어옵니다
5. [샘플 → 종신보험] 을 연 뒤 아래 위험률 표 창 **[파일 올리기] → `06_위험률표_종신_남녀.xlsx`**(또는 .csv) → 연령·사망률·장해율이 남·여로 자동 연결 → 산출방법서 위험률 표에 "40~110세 71행"
6. **[열기] → `07_스캔본_든든건강보험.pdf`** (또는 `_1쪽.png`) → **그림으로 읽기** 창 — 쪽을 고르고 본인의 Anthropic API 키를 넣어 [1쪽 보내기] (약 $0.07). 02 와 같은 이율·사업비가 나오는지 대조합니다(`docs/이미지-PDF-변환-설계.md`)
7. 고쳐서 반영: **[열기] → `01_앱양식_종신보험_산출방법서.tex`** → [LaTeX] 탭에서 `적용이율 i & 2.500` 을 `3.000` 으로 → **[조건에 반영]** → 왼쪽 M03 이 3% 로 바뀌고 조건 파일 주석은 남습니다
8. Word·한글로 고쳐 반영: [샘플 → 종신보험] → **[Word·한글]** 탭 [Word 내려받기] → Word(또는 한글)에서 적용이율 `2.500%` 를 `3.000%` 로, `[식] 순보험료·기준연납순보험료` 아래 식의 `20` 을 `25` 로 고쳐 저장 → **[고친 Word·한글 올리기]** → "basis.interest · formulas" 두 건만 반영

### 시험하다 발견한 점

- **α_P 해석 (고침)** — "초년도 기준연납순보험료 × MIN(보험기간,20) … 12%" 는 이 앱의 영업보험료 식이 α_P 를 20년 기준 배수로 쓰므로 `12% × 20 = 2.4배` 로 읽습니다(보장기간이 20년보다 짧으면 식이 n/20 을 곱함). 실제 문서 2건("3.50%×Min(보험기간, 20년)" → 0.7배, "X MIN(보험기간,20) 15%" → 3배)도 같은 규칙입니다.
- 파일을 열면 조건 **전체가 새 문서로 바뀝니다.** 산출방법서(02)와 사업방법서(03)를 합쳐 한 조건으로 만드는 "더해 읽기"는 아직 없습니다(제안).

| 형식 | 무엇으로 고치나 | 앱에 들어가는 길 | 조건에 들어가는 것 |
|---|---|---|---|
| 입력 카드 | 앱 왼쪽 [입력] | 바로 | 전부 |
| 조건 파일 `.yaml` | 앱 [YAML] 탭, 또는 메모장·VS Code 로 고친 뒤 [열기] | 바로 / 다시 열기 | 전부 (주석 유지) |
| LaTeX `.tex` | 앱 [LaTeX] 탭, 또는 Overleaf·TeX 편집기로 고친 뒤 [열기] | [조건에 반영] | 값만 — 이율·사업비·담보·위험률·계약·가입 조건 (문장 수정은 들어가지 않음) |
| Markdown `.md` | 앱 [Markdown] 탭, 또는 메모장·Typora 로 고친 뒤 [열기] | [조건에 반영] | 값만 (위와 같음) |
| **표준 산출방법서** Word `.docx` · 한글 `.hwpx` | [표준 양식] · [Word·한글] 탭에서 받아 Word·한글에서 고침 (규칙: `standards/README.md`) | [고친 Word·한글 올리기] (바뀐 것만) 또는 [열기] (새로) | 값 + **수식 · 주석 · 절** (Word·한글 수식 편집기로 넣은 식 포함) |
| 다른 양식 Word `.docx` | Word 에서 표 칸·값을 고치고 저장 | [열기] 또는 [고친 Word·한글 올리기] | 표·본문 규칙으로 읽히는 값 |
| 다른 양식 한글 `.hwpx` · `.hwp` | 02 `.docx` 를 한글로 열어 [다른 이름으로 저장 → HWPX 또는 HWP] | 위와 같음 | HWPX 는 표까지, HWP(5.x)는 아직 문단만(사업비 표가 빠질 수 있음 → HWPX 권장) |
| PDF | 고치는 형식이 아님 — Word·한글에서 [PDF 로 저장]한 글자 있는 PDF | [열기] (표가 깨지면 [원문] 탭 [그림으로 다시 읽기]) | 문단·단순한 표 |
| 스캔 PDF · PNG · JPG | 고치는 형식이 아님 | [열기] → 그림으로 읽기 (API 키) | 옮겨 적은 글에서 규칙으로 읽히는 값 |
| MethodSpec `.json` | 자유설계보험 `/method` 가 내보냄 (고급: VS Code) | [열기] | 전부 + 위험률 표 |
| 위험률 표 `.csv` · `.xlsx` | Excel 에서 값을 고치거나, 표를 복사해 위험률 표 창에 붙여넣기(Ctrl+V) | 위험률 표 창 | 연령 × 위험률 값(첫 행은 열 이름) |
| 산출방법서 속 별첨 위험률 표 (PDF·Word·한글) | 첫 열이 연령, 나머지가 값인 표 | [열기] · [고친 Word·한글 올리기] | 위험률 표 창으로 — 열 이름이 위험률 이름과 같으면 바로 이음 |

## 샘플을 만든 방법

- **01** — 앱의 [샘플 → 종신보험] 조건으로 앱이 낸 `.md` · `.tex` → pandoc 으로 `.docx`, 앱 HTML → 크롬 인쇄로 `.pdf`
- **02 · 03** — 손으로 쓴 `.md` (실제 산출방법서·사업방법서 25건의 모양을 본뜸) → pandoc `.docx`, pandoc HTML → 크롬 인쇄 `.pdf`
- **04** — 앱 샘플 "무해지환급형 암보험" 조건 파일
- **05** — 자유설계보험 레시피 "암 진단 + 암입원 특약" → `planToSpec`
- **06** — 자유설계보험에 들어 있는 제7회 경험생명표 사망률 · 80% 이상 장해율(40~110세, 남·여)
- **07** — 02 PDF 1쪽을 그림(PNG)으로 찍고, 그 그림만 넣은 PDF
