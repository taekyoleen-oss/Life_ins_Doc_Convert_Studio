# 표준 산출방법서 (표준 산출방법서 v5)

Word·한글로 고쳐서 앱에 다시 올리는 산출방법서의 **정해진 양식**입니다. 이 양식대로 쓰면 앱이 값뿐 아니라 **수식·주석·절까지** 정확히 읽습니다.

| 파일 | 상품 | 보여 주는 것 |
|---|---|---|
| `표준_산출방법서_종신보험.docx` (· `.hwpx`) | 종신보험 | 사망·80% 이상 장해 — 탈퇴 사유 둘 |
| `표준_산출방법서_질병보험.docx` (· `.hwpx`) | 2대질병 진단보험 | 진단하면 소멸, 80세 만기 |
| `표준_산출방법서_암보험.docx` (· `.hwpx`) | 무해지환급형 암보험 | 적용해지율·환급률 |

> `.hwpx` 는 `scripts/make-standard-hwpx.ps1`(한글 COM)로 `.docx` 에서 만듭니다. v5 로 바꾼 2026-10-01 에는 한글 COM 이 멈춰 만들지 못했으므로 **지금은 `.docx` 만** 있습니다 — 한글을 한 번 직접 띄운 뒤 그 스크립트를 돌리면 생깁니다.

앱에서는 **[Word·한글]** 탭에서 같은 파일을 받습니다. 지금 조건을 이 양식으로 받으려면 [Word 내려받기].

## 문서 모양 (v5)

- 글자 12pt, 절·소제목 14pt. 식 줄은 줄간격 1.5.
- 식은 **Word 수식**(독립 수식)입니다 — 아래첨자·위첨자·분수가 조판되어 나옵니다. 한글에서 열면 한글 수식이 됩니다.
- 식마다 **설명을 위에, 식을 아래에** 둡니다. 한 줄에 식 하나.
- `다. 기호의 정의` — x·t·n(보험기간)·m(납입기간)·k(납입주기별 계수)·i·v·l·l′·d·f·S (해지율이 있으면 w·ρ)를 표로 정의합니다. **l·l′ 은 집단마다 한 줄**입니다 — `l_{x+t}` = t 시점 생존자수(기준인원 l_x = 100,000, 사망하지 않은 생존자수), `l′_{x+t}` = 그 가운데 납입면제 사유(암·80% 장해 등)도 나지 않은 사람. 담보가 곱하는 l 이 집단마다 다르기 때문입니다(암 진단과 암 입원·수술은 탈퇴 사유가 달라 집단이 갈립니다). 위험률 기호는 담보별 식의 첫 줄, D·C·N·P·G·V 는 각 식 위의 설명이 정의합니다. 앱이 조건에서 **늘 다시 만드는** 절이라 담보·집단·납입면제를 고치면 저절로 따라오고, 이 절을 고쳐도 조건에는 들어가지 않습니다.
- 담보마다 세로 표 하나(`담보 | 이름` 아래로 급부 유형·**보험기간**(`100세`)·**보장금액**(`가입금액의 0.5배` — 실무처럼 가입금액 대비 배수)·**면책·삭감**(`90일 면책` · `2년 50% 삭감` · `없음`)·급부/탈퇴 위험률·**집단**). `단위` 행은 특약일 때만, `지급 사유` 행은 조건에 따로 적을 때만 붙습니다. 급부 위험률은 탈퇴 사유 가운데 사망이 아닌 것으로 정해지는 정보 행입니다.
- 보험료·준비금은 모두 보장금액 **1원당**으로 내고 맨 뒤에 가입금액 × 배수를 곱합니다. 1원당 영업보험료는 소수 여섯째 자리까지(`G₁ = round₆(G)`), 10만원당은 원 단위 반올림(`G_{10만}`).
- 벼리는 **큰 장 셋 + 별첨**이고, 장 안을 `가.`·`나.` … 로 나눕니다(실무 양식과 같은 모양):

  ```
  개요
  1. 보험료의 계산에 관한 사항
     가. 예정기초율                     — 이율 · 위험률 · 사업비 · 납입면제 사유(f)
     나. 보장 내용                      — 담보마다 세로 표
     다. 기호의 정의
     라. 유지자수·납입자수              — 집단마다 [식] 유지자수(기준 인원 · Q · l) · [식] 납입자수(f · l′)
     마. 계산기수 — 보험료              — D′ · N′ · N* (납입자수 쪽)
     바. 계산기수 — 보험금              — D · N, 담보마다 S · C · M · PVB (l 은 「라」에서 가져옵니다)
     사. 순보험료 및 영업보험료         — P · 기준연납순보험료 · G · 1원당 반올림 → 10만원당
  2. 책임준비금의 계산에 관한 사항     — P_β · V (· V^{10만}) — 계산할 수 있는 식
  3. 해지환급금의 계산에 관한 사항     — α^{공제} · 해약공제 · W^{표준} · W · 납입누계 · 환급률 — 계산할 수 있는 식
  4. 별첨 — 위험률 표
  ```

- 2·3 장은 `※ 사항` 줄을 **식보다 앞에** 둡니다.
- 납입면제 사유는 `가.` 에 `f_x : 80% 이상 장해율 · 암발생률` 로 사유 전부를 적고, 집단 식은 저마다 `f_x : <그 집단에 남은 사유> — 납입만 면제되는 사유` 로 적습니다 — 담보의 탈퇴 사유이기도 한 사유는 두 번 빼지 않으려고 f 에서 뺍니다.
- 현가율 값(v^t)은 싣지 않습니다 — 적용이율에서 계산합니다.
- 위험률 표 창에 이은 값 표가 있으면 맨 뒤에 `N. 별첨 — 위험률 표`(연령 × 위험률, 남·여 열) 가 붙습니다. 되읽으면 위험률 표 창으로 돌아갑니다.

| 기호 | 뜻 |
|---|---|
| q · r | 사망률 · 급부 발생률(진단·장해 등) — 담보별 식의 첫 줄에서 위험률 이름과 함께 정의 |
| f | 납입만 면제되는 사유의 발생률 |
| w | 적용해지율 |
| k | 납입주기별 계수 — 연 납입횟수(연납 1 · 월납 12) |
| ρ | 저해지·무해지환급형의 납입기간 중 해지환급금 비율 |

## 고치고 올리는 순서

1. 받기 — `.docx`(Word) 또는 `.hwpx`(한글).
2. 고치기 — 아래 규칙대로.
3. 올리기
   - **[고친 Word·한글 올리기 → 조건에 반영]**: 바뀐 것만 지금 조건에 들어갑니다(조건 파일의 주석·순서는 그대로).
   - **[열기]**: 이 문서로 조건 전체를 새로 만듭니다.
4. 출력 — [Word (작성 안내 없이)] 또는 [PDF 저장](인쇄 → PDF — 수식이 조판되어 나옵니다).

## 쓰는 규칙

| 자리 | 규칙 |
|---|---|
| 개요 표의 **`양식 \| 표준 산출방법서 v5`** 행 | 지우지 않습니다. 앱은 이 행을 보고 정해진 순서대로 읽습니다. 이 행이 없으면 표·문장에서 값만 읽습니다. v1~v4 문서도 계속 읽습니다(이름·글이 바뀐 옛 자동 식은 들이지 않습니다) |
| 절 제목 (`1. 보험료의 계산에 관한 사항` …) · 소제목 (`가. 예정기초율` …) | 번호와 이름을 그대로 둡니다. 소제목은 `가.`~`하.` 로 시작하는 줄입니다 |
| 표의 머리글(첫 행) | 그대로 둡니다. 값 칸을 고치고, 행을 더하거나 지웁니다 — 위험률 · 사업비 · 가입 조건 행이 조건에 더해지고 빠집니다(위험률은 담보가 쓰지 않는 행만 빠집니다). 담보는 세로 표를 통째로 더하거나 지우고, 면책을 `없음` 으로 두거나 `※ 담보: 연령 구간 배수 …` 줄을 지우면 그 칸도 조건에서 빠집니다 |
| 위험률 표의 **기호** 칸 | 담보 표의 급부·탈퇴 위험률이 이 기호의 위험률을 가리킵니다(`q`, `r80` …). 담보 표에 위험률 표에 없는 이름을 적으면 그 이름으로 위험률이 더해지고 유형을 확인하라고 알립니다 |
| **별첨 — 위험률 표** | 첫 열이 연령, 나머지가 위험률 값. 값을 고치거나 열을 더하면 위험률 표 창에 들어가고, 열 이름이 위험률 이름과 같으면 바로 이어집니다(`사망률(남)` 처럼 성별을 붙이면 남·여 열). 다른 양식의 산출방법서도 이런 표가 있으면 같은 방식으로 가져옵니다 |
| 사업비 표의 **구분** 칸 | `계약체결비용 (초년도)` 처럼 괄호 안이 적용 시기(초년도·납입중·납입후) |
| **수식** | `[식] 제목` 줄 아래에 설명 줄(한글, `=` 없음)과 식 줄을 번갈아. 식에 대한 덧붙임은 식 아래 `※` 로 시작하는 줄 |
| 수식 고치기 | Word 수식 편집기(식을 누르면 열림)나 한글 수식 편집기로 고칩니다. 평문 표기(`l_{x+t}` · `v^{t}` · `( a )/( b )` · `Σ_{u≥t}` · `′`)로 적어도 읽습니다 |
| 식 더하기 | 알맞은 절에 `[식] 새 제목` 줄과 식 줄을 넣습니다 → 조건의 M09 따로 적는 식 |
| **식이 계산에 쓰입니다** | 식 표기는 앱이 그대로 읽어 계산합니다 — 고친 식으로 보험료·준비금·환급금이 바뀝니다(계산 표·엑셀·파이썬까지). 계산에 쓰이려면 아래 문법을 지킵니다: 아래첨자는 자리(`x` = t 0 · `x+t` · `x+t+1` · `t` · `u` · 수), 합은 `Σ_{u≥t}` 또는 `Σ_{u=t}^{n−1}`, 조건은 `if( t = 0, 참, 거짓 )`(비교는 `40 ≤ x+t ≤ 59` 처럼 이어 쓸 수 있고 `[t≤m]` 은 1/0), 그 밖에 `min` · `max` · `round` · `round₅` · `round₆`. 이름의 위첨자는 `W^{표준}` · `α^{공제}` 처럼 `{}` 로 묶습니다. 문법을 벗어난 줄은 문서에는 그대로 실리고 계산에서만 빠집니다(앱이 "계산 제외" 로 알립니다) |
| 자동 식과 고친 식 | 앱이 조건에서 만드는 식과 같으면 조건에 따로 싣지 않고, **고친 식만** 조건에 들어가 자동 식을 대신합니다 |
| 책임준비금 · 해지환급금 관련 사항 | `※` 로 시작하는 줄 하나가 사항 하나. `해약공제는 납입기간과 7년 중 …` 의 숫자가 해약공제 기간 |
| 새 절 | `5. 기타 사항` 처럼 번호를 붙인 절을 더하면 원문 절로 보존됩니다 |
| 맨 앞 **작성 안내** 표 | 앱은 읽지 않습니다. 지워도 됩니다 |

## 상품을 더하려면

`lib/standards.ts` 의 `STANDARDS` 에 한 줄(이름 + 조건)을 넣고 아래를 돌리면 `표준_산출방법서_<이름>.docx` 가 생깁니다.

```bash
STANDARDS_UPDATE=1 node node_modules/vitest/vitest.mjs run tests/standards-files.test.ts
```

`.hwpx` 는 `powershell -ExecutionPolicy Bypass -File scripts/make-standard-hwpx.ps1`(한글 COM — `.docx` 를 열어 수식 개체마다 `BaseUnit` = 1200(12pt)으로 맞춘 뒤 HWPX 로 저장)로 만들고, 시험이 되읽어 같은 조건인지 확인합니다(파일이 없으면 건너뜁니다). 한글에서 직접 [다른 이름으로 저장 → HWPX 문서] 해도 됩니다.
양식 자체를 바꾸고 싶으면(행·절·표기) 요청해 주세요 — 앱의 읽기·쓰기를 함께 고치고 판을 올립니다. 옛 판 문서도 계속 읽게 둡니다.

## 한계

- 담보 표의 `단위` 행(특약 이름)은 되읽습니다(그 이름의 탭이 됩니다). 주계약과 다른 특약 조건(`units[].overrides`)은 아직 문서로 오가지 않습니다 — MethodSpec JSON 을 씁니다.
- 저해지형의 해지급부 현가 `CSV` 는 이 앱이 0 으로 두고(표준형 보험료·준비금) 그 값은 자유설계보험이 냅니다.
- 자동 식을 문서에서 지워도 조건에서 다시 만들어집니다(식을 없애는 방법은 아직 없음).
- 한글은 Word 의 글 속 수식(문장 안의 식)을 버리므로, 앱은 식 줄만 독립 수식으로 쓰고 글·표 속 기호(`α_S`)는 글자 첨자로 씁니다.
