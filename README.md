# Life_ins_Doc_Convert_Studio — 산출방법서 ↔ 조건 변환기

**조건을 넣으면 산출방법서가, 산출방법서를 넣으면 조건이 나오는** 독립 웹앱.
위 왼쪽은 조건(입력 카드 · YAML), 위 오른쪽은 그 조건으로 만든 산출방법서, 아래는 위험률 표다. 창 사이 막대로 크기를 바꾸고 창마다 전체 보기·숨기기가 된다.

## 주요 기능

- 🗂️ **조건 입력 카드 — 산출 순서대로** — 카드를 산출 순서로 늘어놓아 한 번에 하나만 펼친다(고른 카드는 테두리가 진해지고 바탕이 달라진다). 카드를 열면 오른쪽 산출방법서에서 그 항목이 함께 표시된다.
  카드 위에 **[시산보험료 조건]** 이 따로 있다 — 성별·가입나이·납입기간·납입주기를 고르면 10만원당·월 보험료가 그 자리에서 나온다(계약 한 점은 조건에 저장하지 않는다).

  | | 카드 | 하는 일 |
  |---|---|---|
  | M01 | 상품 기본정보 | 이름·종류와 **가입 조건**(보험의 종류·종목·보험기간·납입기간·가입나이·납입주기·한도·갱신 — 사업방법서 판매 범위 표 모양) |
  | M03 | 이자율·저해지 | 적용이율·표준이율·적용해지율·환급률 |
  | M04 | 위험률 | 위험률 이름·유형·근거. 값 표는 아래 위험률 표 창에서 잇는다 |
  | M05 | **보험료** — 유지자수·납입자수 (l · l′) · 보험료의 현가 | 기준 인원 10만에서 탈퇴 사유로 줄여 l, 납입면제 사유까지 빼서 l′, 그 현가 D·D′ 와 누계 N·N′·N\*. **탈퇴 사유가 같은 담보는 한 집단** |
  | B01 | **보장 (담보)** — 담보 하나가 한 덩이 | 담보를 여기 한 군데서 더하고(복사도) 고친다 — 급부 위험률·보장금액·보장 종료 나이·**면책기간**·집단, 그리고 그 담보의 **보험금의 현가**(지급자수 d → 현가 C → 누계 M → PVB)까지 한 덩이로. **l 은 M05 의 집단에서 그대로 가져온다**([M05 에서 보기]) |
  | M06 | 사업비 | α_S · α_P · β_S · β_G · β′ · γ |
  | M07 | 보험료의 계산 (P · G) | 순보험료 · 기준연납순보험료 · 영업보험료 |
  | M08 | 책임준비금·해지환급금 | 해약공제 기간·문장·식 |
  | M09 | 따로 적는 식 | 표준 식 말고 새로 적는 식(새 절도 만들 수 있다) |

  머리의 **[수식 숨기기/보이기]** 로 카드의 식을 감추거나 보일 수 있다(값만 볼 때).
  이 앱은 **산출방법서의 전체 정보만** 다룬다 — 보험료를 계산할 계약 한 점(성별·가입나이·보험기간·납입기간·납입주기·가입금액)은 조건에 저장하지 않는다([시산보험료 조건]과 [보험료 계산] 화면에서 고르는 값이며, 자유설계보험 상품 만들기의 **M02 계약정보**가 정식 자리다. 그래서 여기는 M02 카드가 없다). [YAML] 탭은 같은 조건의 파일 보기 — 칸을 고치면 그 값만 파일에 들어가 주석·줄 맞춤이 남는다.
- 🧮 **보험료 계산 (엑셀처럼)** — 머리의 **[＝ 보험료 계산]** 을 누르면 담보마다 한 해 한 줄의 표가 열린다.
  - **왼쪽**: 계산에 앞서 정한 값 — 가입나이 x · 보장기간 n · 납입기간 m · 납입주기 k · 적용이율 i · 현가율 v · 보장금액 · 면책 · 사업비(α_S·α_P·β_S·β_G·β′·γ).
  - **표**: **위험률 → 현가율 v^t · v^{t+½} → 유지자수 l · 납입자수 l′ · 지급자수 d → 그 현가 D·D′ 와 누계 N·N′ → 보장금액 배수 S · 급부 현가 C · 누계 M**, 그 옆에서 **N\* · PVB · P · 기준연납 · G · 10만원당 · 담보 보험료**.
  - **열 제목이나 값을 누르면 그 값을 만든 식과 그 해에 쓰인 값**이 옆에 나온다(엑셀에서 칸을 눌러 수식을 보는 것과 같다).
  - 값은 이 앱이 산출방법서의 식을 읽어 낸 것이고, 자유설계보험 엔진·엑셀 검산과 같다.
- 📊 **엑셀로 내려받기 (수식 포함)** — 계산 화면의 [엑셀로 내려받기] 는 **값으로 두는 것이 계약·기초율과 위험률뿐**인 `.xlsx` 를 만든다. 현가율부터 유지자수·납입자수·지급자수·계산기수·보험료까지는 모두 **엑셀 수식**이다(`=L2*(1-K2)` · `=SUM(O3:O73)` · `=SUMPRODUCT(S3:S72,T3:T72)`). 담보마다 한 장이고 첫 장이 합계다. 그래서 **이 파일 하나만으로** 산출 과정을 따라가고, 위험률이나 이율을 바꿔 다시 계산해 볼 수 있다 — 엑셀이 다시 계산한 값이 앱과 같은지 확인했다(차이 0).
- ✏️ **조건 → 산출방법서** — 조건을 고치면 오른쪽 산출방법서가 바로 바뀐다. 유지자수·납입자수·현가·보험료·준비금·해지환급금 식은 조건에서 자동으로 만든다(KaTeX).
- 🧠 **식이 곧 계산이다** — 산출방법서에 싣는 평문 수식 표기가 그대로 기계가 읽는 문법이다(`lib/methoddoc/calc.ts`). M05·B01·M07·M08 카드에서 **[식 고치기]** 로 식을 고치면 산출방법서가 바뀌고 같은 자리의 시산 값도 따라 바뀐다([되돌리기]로 자동 식으로 돌아간다). Word·한글에서 식을 고쳐 올려도 같은 자리에 들어온다. 다른 앱은 `lib/methoddoc` 만 가져다 `computeSpec(spec, 계약)` 을 부르면 산출방법서에 실린 식대로 보험료를 낸다 — 자유설계보험 엔진과 10만원당 보험료가 같은지 시험이 확인한다.
- 📊 **위험률 표 ↔ 조건 ↔ 계산** — Excel 표 붙여넣기·CSV·TSV·XLSX 를 올리면 첫 행을 열 이름으로 읽고, 같은 이름의 위험률(M04)에 잇고 조건에 없는 이름의 열은 새 위험률로 M04 에 더한다. 거꾸로 M04 에서 위험률을 더하면 표에 빈 열이 생기고, 산출방법서에서 더해 올려도 같다(지우면 연결 해제). 값 표가 없는 위험률은 상태줄·M04 가 알려 준다(계산 앱에서 0). 표 창에서 칸을 누르면 값을, 머리를 두 번 누르면 열 이름을, [잇기] 아래에서 이은 위험률의 유형을 바로 고친다. 이은 열은 산출방법서 위험률 표·맨 뒤 "별첨 — 위험률 표"와 MethodSpec JSON 에 실린다 — 남·여 열이 있으면 두 벌 다(`RateRef.tables`), 자유설계보험이 계약정보 성별의 표를 고른다. 산출방법서(PDF·Word·한글)에 연령 × 위험률 값 표가 있으면 열 때 이 창으로 들어온다.
- ∑ **수식·기호 견본** — 산출방법서 탭 [＋ 수식 더하기]는 견본 식(유지자수·계산기수·보험료·준비금·해지환급금)을 조건 식으로 더하고, LaTeX·Markdown 탭 [수식·기호 견본]은 커서 자리에 식·기호·절 제목·표를 넣는다.
- 📄 **표준 산출방법서 (Word·한글)** — 앱이 정확히 되읽는 양식(`표준 산출방법서 v4`). [Word·한글] 탭에서 상품별 견본(`표준_산출방법서_종신보험` · `_질병보험` · `_암보험`, .docx · .hwpx)을 받거나, 지금 조건을 [Word 내려받기] 해서 Word·한글에서 표의 값·행, `[식]` 아래 식 줄, `※` 설명을 고친 뒤 **[고친 Word·한글 올리기]** 하면 바뀐 값·식·주석만 조건에 들어간다. Word·한글 수식 편집기로 넣은 식도 읽는다. 쓰는 규칙: [`standards/README.md`](standards/README.md)
- 📥 **산출방법서 → 조건** — PDF·DOCX·HWP(5.x)·HWPX·TEX·MD 를 열거나 창에 끌어다 놓으면 조건으로 옮긴다. 표준 산출방법서는 식·주석·절까지, 다른 양식은 표·본문 규칙으로 읽히는 값을 읽는다. 값 옆 주석이 원문 위치·확신도다.
  **표준 양식이면 PDF 도 Word 와 똑같이 읽는다** — 글자 좌표로 표의 열과 첨자(`l_{x+t}`·`v^{t+½}`)까지 되살려, PDF 하나만 올려도 담보·위험률·별첨 위험률 표가 들어오고 보험료가 나온다(`samples/10_기본상품_…` .docx ↔ .pdf 로 시험).
- 🖼️ **그림으로 읽기** — 스캔 PDF·PNG·JPG 는 쪽을 골라 **본인의 Anthropic API 키**로 보내면 Claude(claude-opus-5)가 쪽을 글로 옮겨 적고, 그 글을 같은 규칙이 읽어 조건으로 만든다(쪽당 약 $0.07, 보내기 전에 예상 비용 표시). 키는 이 브라우저에만 둔다.
- 🔗 **대응 위치** — 조건 한 줄을 고르면 그 조건이 만든 표의 행·수식·원문 근거 줄이 앰버색으로 표시되고, 오른쪽을 누르거나 끌어서 고르면 왼쪽 조건 줄이 표시된다.
- 📝 **LaTeX·Markdown 으로 고치기** — 탭에서 산출방법서 원문을 고친 뒤 [조건에 반영] 하면 바뀐 값만 조건에 들어간다. 조건 파일의 주석·순서는 지킨다.
- 📄 **원문 탭** — 불러온 문서를 본문 N줄·표 N 단위로 보여 주고, 줄마다 거기서 읽은 조건을 딱지로 단다. PDF 는 원본 보기도 된다.
- 📚 **샘플** — 종신(사망·80% 장해) · 2대질병 · 무해지 암 · 납입지원 조건, 그리고 LaTeX·Markdown 산출방법서 고쳐 보기.
- 🏠 **기본 상품 — 종신보험(암진단 포함)** — 첫 화면이 사망·80% 이상 장해(1억) + 암 진단(사망보험금의 50%, 90일 면책) 에 80% 장해·암 진단 시 납입면제인 상품과 그 위험률 표(사망률·장해율·암발생률 모두 남·여)로 열린다. 옛 종신보험은 [샘플] 에 있다.
- 📚 **기본 위험률 모음** — 위험률 표 창·M04 의 [기본 위험률 모음]에서 공개 기본 위험률(사망률·80% 장해율·암·2대·3대질병, 남·여)과 — 이 PC 에 있으면 — 사내 위험률 모음을 골라 표에 넣고 조건의 위험률에 잇는다. 사내 모음은 `python scripts/import-rate-library.py` 가 `private/` 에만 만든다(외부 반출 금지 — 깃·배포 제외).
- 🧮 **엑셀 검산** — `samples/09_종신보험(암진단포함)_검산.xlsx` 는 기본 상품의 산출방법서 식(계산기수·보험료·연말 준비금)을 엑셀 수식으로 적은 파일이다. 자유설계보험이 계산한 값과 나란히 두어 차이가 0 인지 보인다(`scripts/check-verify-xlsx.ps1` 가 엑셀로 다시 계산해 확인).
- 📦 **패키지 · 최근 작업** — [패키지 → 패키지로 저장]은 조건(YAML)·산출방법서(Word·Markdown)·MethodSpec JSON·위험률 표(CSV)를 한 파일 `.lifepkg`(압축하지 않은 ZIP — 이름을 .zip 으로 바꾸면 안의 파일을 꺼낼 수 있다)로 저장한다. 위험률 표가 없어도 된다. [패키지 열기]·[열기]·끌어다 놓기로 되살리고, 저장·연 것은 [최근 작업]에 남아 한 번에 불러온다. 첫 화면과 [샘플]도 조건·산출방법서·위험률 표(가상의 값)가 한 세트다.
- 📤 **내보내기** — 조건 `.yaml`, 다른 앱용 `MethodSpec .json`(위험률 표 포함 — 자유설계보험 `/method` 에서 열면 상품 만들기 설계 전체가 된다), 산출방법서 Word `.docx`(표준 산출방법서 — 한글에서도 열림) · `.tex`(xelatex+kotex) · `.md` · `.html`(수식 포함) · 인쇄/PDF.
- 🔁 **자유설계보험과 왕복** — [내보내기 → 자유설계보험으로 보내기]로 MethodSpec JSON 을 저장하고, 자유설계보험의 **[산출방법서 변환기]** 화면에 그 파일을 올리면 **이 파일로 계산한 보험료**가 바로 보이고 [상품 만들기에 넣기]로 설계 전체가 된다. 거꾸로 그쪽이 낸 JSON 을 여기서 열면 조건은 입력 카드로, 위험률 표는 아래 위험률 표 창으로 들어온다.
- 💾 브라우저 자동 저장(localStorage — 조건 · 위험률 표와 연결 · 화면 나눔). 서버·로그인 없음.

## 조건 파일 (YAML ↔ MethodSpec)

```yaml
meta:     { productName: 종신보험, kind: 표준형(완전 환급) }
basis:    { interest: 2.5%, standardInterest: 3.25%, waiver: false }
rates:
  - { id: q,   name: 사망률, role: death }
  - { id: r80, name: 80% 이상 장해율,        role: incidence }
expenses:
  - { group: 계약체결비용, symbol: α_S, basis: 보험가입금액, rate: 1% }
benefits:
  - { id: b1, name: 사망·80% 이상 장해, role: death, amount: 100000000, endAge: 110, exitRateIds: [q, r80] }
```

- 이율 `2.5%`, 사업비 `1.5/1000`, 배수 `1배` 처럼 실무 표기로 쓴다(읽을 때 소수로 바뀐다).
- 위험률 유형: `death` 사망 · `incidence` 최초발생 · `recurring` 반복지급 · `waiver` 납입면제 · `other`.
- 탈퇴 사유가 둘이면 탈퇴율 `Q = q + r − q·r/2`, 유지자수·납입자수는 `l(1 − Q)` — 따로 둔 납입면제율을 곱하지 않는다.
- 다른 앱과는 **MethodSpec JSON** 으로 주고받는다(`lib/methoddoc/spec.ts`).
