# [공유] 산출방법서 ↔ 조건을 한 화면에서 — 계리 실무용 웹앱 시험판을 소개합니다

안녕하세요. 보험료 산출방법서를 쓰고 검산하는 일을 하면서 늘 아쉬웠던 부분을 조금 덜어 보려고 웹앱을 하나 만들어 보았습니다.
아직 시험판이지만, 같은 고민을 하시는 분들께 써 보시고 의견을 듣고 싶어 가볍게 소개드립니다.
자세한 화면과 사용 방법은 **첨부한 카드뉴스(PDF, 8장)** 에 정리해 두었습니다.

👉 바로 써 보기: https://lifeinsdocconvertstudio.vercel.app
(설치·로그인 없이 브라우저에서 열립니다. PC 화면을 권장합니다.)

## 왜 만들었나요

이율 하나, 위험률 하나만 바뀌어도 산출방법서 · 검산 엑셀 · 사업방법서를 따로 고치다 보면 어딘가 어긋나기 쉽습니다.
문서에 적힌 식과 실제 계산이 같은지도 결국 눈으로 확인해야 하고요.
그래서 **조건 하나를 고치면 산출방법서와 보험료 계산이 함께 따라오는 도구**를 목표로 했습니다.

## 이런 걸 할 수 있어요

- **조건 카드 = 산출방법서 차례**
  문서 정보 → 상품 → 이율 → 위험률 → 사업비 → 위험률 합성 → 유지자 → 보험금 → 보장 → 보험료 → 준비금 순서의 카드를 고치면, 오른쪽 표준 산출방법서가 바로 바뀝니다. 카드를 열면 문서의 그 자리가 강조되고, 문서를 누르면 조건으로 돌아옵니다.
- **식이 곧 계산**
  산출방법서에 적힌 식(유지자 lx, 위험률 합성, Cx · Mx, 영업보험료 G …)을 그대로 읽어 보험료를 냅니다. 식을 고치면 계산도 바뀝니다. 위험률 기호는 예정위험률 표에서 정한 기호(qx · rc …)를 그대로 씁니다.
- **보험료 계산 표와 검산**
  한 해 한 줄의 엑셀식 표로 위험률 → 현가율 → 계산기수 → 준비금 · 환급금까지 보여 주고, 값을 누르면 그 값을 만든 식이 나옵니다. **엑셀(수식 포함)** 과 **Python** 으로 내려받아 직접 검산할 수 있습니다.
- **주계약 · 독립특약**
  특약은 주계약 아래에 따로 한 권처럼(1~3장) 싣고, 자체 예정기초율 · 유지자 · 납입자로 산출합니다.
- **Word 산출방법서로 내보내기 / 불러오기**
  표준 양식 Word 로 내보내고, 회사 산출방법서(Word · PDF · 한글)를 불러오면 조건으로 읽어 들입니다.

## 써 보는 방법 (4단계)

1. 상단 **[샘플]** 에서 *종신보험* 또는 *암보험(주계약 + 특약 둘)* 을 엽니다.
2. 왼쪽 카드에서 이율 · 위험률 · 보장(배수 · 면책 · 삭감) 등을 고쳐 봅니다.
3. **[= 보험료 계산]** 으로 결과를 보고, 엑셀 · Python 으로 내려받아 검산해 봅니다.
4. **[내보내기] → Word** 로 산출방법서를 받아 봅니다. 작업은 **[패키지로 저장]** 으로 보관할 수 있어요.

## 미리 말씀드릴 점

- **시험판**입니다. 실무에 그대로 쓰시기보다는 구조와 흐름을 살펴보시는 용도로 봐 주세요.
- 들어 있는 위험률은 공개 시험용 **가상 표(경험생명표(가상))** 입니다. 실제 표는 [위험률 표 → 파일 올리기] 로 붙여 넣으실 수 있습니다.
- 서버 없이 동작해서, 작업 내용은 **쓰시는 브라우저에만** 저장됩니다.
